# CSS / Next.js 16 repair

## Fixes included
- Moved the Phase C3 stylesheet `@import` to the top of `src/app/globals.css`.
  CSS `@import` rules must appear before ordinary rules and Tailwind directives.
- Kept all three template stylesheet imports together at the top of the global stylesheet.
- Updated the SEO verification script: this codebase uses `html-to-image` via dynamic import,
  not `html2canvas`; the old verification assertion was stale.
- Declared Node.js >=20.9.0, required by Next.js 16.
- Kept ESLint 9 compatible with `eslint-config-next` 16.

## Windows clean install
Use Node.js 22 LTS (or another supported version >=20.9.0).

From the project root in CMD:

```bat
node -v
npm -v
rmdir /s /q node_modules
del package-lock.json
npm install
npm run verify:source
npm run verify:build-readiness
npm run verify:templates
npm run verify:seo
npm run typecheck
npm run build
npm run dev
```

If `rmdir` or `del` says the file/folder does not exist, continue.

Do not use `--force` or `--legacy-peer-deps`. If any command fails, share the first complete error block.
