# Build Bug Fix — 2026-10-07

## Reported failure

Next.js failed during compilation in `src/components/biodata/templates/phaseB/BlushRoseFloral.tsx`:

`Module not found: Can't resolve '../template-contract'`

## Root causes found

1. `src/components/biodata/template-contract.ts` was missing from the Phase 7 package even though every template imported it.
2. Template files under `src/components/biodata/templates/*` used the wrong relative path for `template-contract.ts`. The correct path from a phase directory is `../../template-contract`.
3. Phase C/C2/C3 templates used `../templates/phaseB/SharedTemplateParts`, which resolves to a non-existent `templates/templates` directory. The correct path is `../phaseB/SharedTemplateParts`.
4. `TemplateRegistry.tsx` had a client boundary even though server-rendered SEO pages use its template registry and render templates. The client directive was removed so the registry is server-compatible.
5. `colorwayVariables()` was simplified to return the imported `CSSProperties` type directly.
